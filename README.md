# VaultPass
Android পাসওয়ার্ড ম্যানেজার (Kotlin + Jetpack Compose) — Autofill Service সহ।

## GitHub Actions দিয়ে APK
1. এই ফোল্ডার GitHub repo-তে push করুন (main branch)।
2. Actions ট্যাবে "Build APK" রান হবে; শেষে Artifacts → VaultPass-APK ডাউনলোড করুন।
3. `git tag v1.0.0 && git push --tags` দিলে Releases পেজেও APK যুক্ত হবে।

অ্যাপ → সেটিংস → "অটোফিল চালু করুন"।
